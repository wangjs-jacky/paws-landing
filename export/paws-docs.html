GETTING STARTED
Installation & Quick Start
Get Paws running in under two minutes. Install the CLI on the computer where your coding agents run, then pair it with the mobile app.
1
Install the CLI
Paws ships as a single npm package. Install it globally on the machine where your agents run:
$ npm i -g paws
2
Connect your computer
Start the relay and leave it running — this is what your phone securely talks to.
$ paws
→ Paws relay started on this machine
✔ waiting for a device to pair…
3
Run your first session
Open the Paws app, scan the pairing code, then spawn a session — right from your phone.
# in the app: tap + → New Session
✔ agent running · Kirills-MacBook-Pro
◐ streaming terminal to your phone
You're all set. Head to Sessions to learn how to steer, pause, and approve agent runs from anywhere.
